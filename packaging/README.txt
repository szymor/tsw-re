Tower of the Sorcerer: Revisited
================================

A faithful remake of Tower of the Sorcerer 1.2 by vamastah.

Original game: Maho no To by NAO (PC-98, 1996).
Windows version: Oz & Kenichi.

Running
-------
Windows: start tsw-re.exe.  Keep the data folder beside it.
Linux:   run bin/tsw-re (needs SDL3, SDL3_image, SDL3_ttf, SDL3_mixer).

The game is played with the keyboard: the arrows move, Enter uses items,
Esc opens the menu (Help > Controls lists the rest).

Saves and options
-----------------
Windows: %APPDATA%\tsw\
Linux:   ~/.local/share/tsw/ (or $XDG_DATA_HOME/tsw/)

The saves use the original game's format (save1.dat .. save8.dat).

Licences
--------
The licences of the libraries and the font are in the licenses folder
(Linux: share/doc/tsw-re/) and data/fonts/.
